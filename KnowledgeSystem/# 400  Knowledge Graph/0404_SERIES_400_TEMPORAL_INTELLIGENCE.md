3. TEMPORAL DIMENSION MODEL

Temporal intelligence operates across four dimensions:

3.1 ABSOLUTE TIME

Definition:
Fixed timestamp-based ordering of events.

Characteristics:

deterministic
externally anchored
used for canonical sequencing
3.2 RELATIVE TIME

Definition:
Ordering based on relationships between events.

Examples:

before / after
during / overlapping
sequential dependency chains

Characteristics:

context-dependent
relationally derived
3.3 DURATIONAL TIME

Definition:
Representation of event spans.

Examples:

long-running processes
continuous ingestion cycles
extended system operations

Characteristics:

start/end boundaries
lifecycle-aware
3.4 CAUSAL TIME

Definition:
Time interpreted through cause-effect relationships.

Examples:

ingestion causes normalization
event triggers recommendation
system update propagates changes

Characteristics:

dependency-driven
logic-based sequencing
