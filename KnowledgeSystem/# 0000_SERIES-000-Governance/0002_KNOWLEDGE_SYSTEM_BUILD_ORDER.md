# PURPOSE

This document defines the REQUIRED order that ALL documentation is created.

Nothing is allowed to be documented randomly.

Every document exists because another document depends on it.

The Knowledge System itself is a software project.

Documentation is treated exactly like source code.

---

# PRINCIPLE

The system can only become self-documenting if every layer is built before the next.

Order matters.

Dependencies matter.

Every document eventually becomes executable knowledge.
