LEGAiSEE — LUXURY SCROLLTELLING SITE MASTER PLAN
1. Core Concept
The site should stop behaving like a collection of webpages.
It should behave like one private architectural experience composed of multiple rooms.
The visitor enters LEGAiSEE through the Home page.
Home establishes:
What this is. Why it matters. What is wrong. What LEGAiSEE does. What makes it different. And why the visitor should continue.
Then the deeper pages become progressively more specialized rooms in the same experience.
The visitor should feel as though they are moving:
Entrance → Discovery → Excavation → Method → Qualification → Architect → Practitioner → Evidence → Commission → Registry
The pages remain separate URLs.
But visually, narratively, and behaviorally, they should feel like one continuous LEGAiSEE world.

4. What "Luxury" Means Here
Luxury does not mean:
gold everywhere
giant text everywhere
expensive-looking gradients
excessive animation
glassmorphism
glowing borders
random particles
flashy transitions
parallax on everything
huge video backgrounds
excessive rounded cards
generic "premium" UI
Those are ways to decorate a website.
Luxury is primarily about:
Restraint
Nothing is fighting for attention.
Space
Content has room to exist.
Pace
The visitor isn't rushed.
Materiality
Elements feel like physical objects.
Hierarchy
The visitor always knows what matters.
Precision
Every transition has a reason.
Exclusivity
The site doesn't behave as though it needs everyone.
Confidence
The site doesn't constantly yell:
LOOK HOW PREMIUM WE ARE.
Instead, it behaves as though it already knows its value.

20. Global Design Rules
These should become actual build governance.
RULE 01 — Preserve Content
Do not rewrite the underlying LEGAiSEE intellectual property simply to make the design easier.

RULE 02 — Preserve URLs
Existing pages remain independently addressable.

RULE 03 — Preserve Architecture
Do not introduce a new framework or rewrite the site architecture simply to implement visual effects.

RULE 04 — Index Means Overview
index.html is the primary overview.
It does not become the portfolio.

RULE 05 — Every Page Must Tell a Story
No page should simply be:
heading
paragraph
cards
paragraph
CTA

RULE 06 — Every Animation Must Have a Narrative Purpose
If removing an animation doesn't change the story, the animation probably doesn't belong.

RULE 07 — No Scroll-Jacking
Never hijack the visitor's scroll control.
Native scrolling remains intact.

RULE 08 — No Animation Overload
Luxury requires restraint.
The visitor should notice the experience, not the JavaScript.

RULE 09 — No Generic UI
Avoid:
generic cards
generic gradients
template-looking sections
excessive pills
meaningless glass panels
stock SaaS layouts

RULE 10 — Breathing Room Is Mandatory
Sections should have enough vertical space for the visitor to understand what they are seeing.

RULE 11 — Motion Has Hierarchy
Primary elements move less.
Secondary elements can move more.
Background elements can move slowly.
Nothing should compete with the message.

RULE 12 — Mobile Is Not an Afterthought
The cinematic experience must be designed to survive:
desktop
tablet
mobile
Parallax may be reduced on mobile rather than forcing expensive effects onto small screens.

The site should create a progression from:
dark → light
unknown → known
buried → excavated
raw → refined
fragmented → structured
drift → clarity
clarity → authority
authority → invitation
That progression is already embedded in LEGAiSEE's content.
The redesign shouldn't invent a luxury story.
It should reveal the story that's already there.
That is the key distinction between merely "making the website look luxurious" and turning LEGAiSEE into a luxury scrollytelling experience. The current Home page already contains the raw narrative—from the Private Record and Narrative Drift through the five restoration stages, Bedrock, ten frameworks, and the Private Registry.
