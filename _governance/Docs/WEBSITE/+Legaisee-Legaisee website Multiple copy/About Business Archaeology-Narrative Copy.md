Tiered Source Hierarchy (Tier 1–4)
Not all evidence is equal. We grade every source according to its reliability:
Tier 1 → Verified: Confirmed, irrefutable evidence
Tier 2 → Probable: Highly credible, very likely accurate
Tier 3 → Plausible: Reasonable, with supporting context
Tier 4 → Uncertain: Speculative or conflicting
By explicitly naming tiers, we communicate discipline and procedural rigor—clients see a method, not assumptions.
Triangulation Protocol
Conflicting information is inevitable. When sources contradict, we:
Document every claim
Assess credibility by tier
Synthesize using context and historical patterns
For example, if a marketing ledger conflicts with memory testimony or TV advertising records, we trace each thread, identify anomalies, and reconcile insights without bias.
3-Source Rule

One Tier 1 verified source
This non-negotiable constraint proves discipline and builds trust—we follow rules we refuse to break.
