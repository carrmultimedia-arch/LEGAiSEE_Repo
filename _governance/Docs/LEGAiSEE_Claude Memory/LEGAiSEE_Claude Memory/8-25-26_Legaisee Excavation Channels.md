Headline finding: "excavation" means 3 completely unrelated things in this codebase
1. modules/excavation_module.php (309 lines) — REAL, live, one of the most substantial genuinely-working features found in the whole audit. Wired via kernel/module_registry.php → shell.php sidebar. Scans real client artifact files (both the case-file structure and legacy artifact-metadata structure), does real keyword-based signal extraction — using the SAME vocabulary as legaisee-recommendation-micro-audit's live module (ops_delay, pricing_pressure, lead_friction, labor_issue), confirming a genuine shared pipeline vocabulary across two modules. Calls real engine/entity_extraction_engine.php + kernel_db(), clusters artifacts by signal, generates executive narrative text per cluster, auto-creates real case JSON files on disk, returns proper UIC-contract output (type=report). Has its own standalone CLI test harness (test_excavation_module.php) confirming it runs successfully.
2. excavation_engine.php (root) + api/excavation_run.php → api/excavate.php — a FAKE chain that writes garbage into the REAL database.
Root excavation_engine.php: hardcodes the SAME test network_id already found in legaisee-brain-micro-audit's build_edges.php ("net_69eee12e374d30_99173905" — confirms this is a shared fake-testing constant reused across the fake ecosystem). Simulates 3 fake "AI platform" (chatgpt/claude/gemini) responses as canned strings, computes a fake "strength" score from strlen(), then makes a REAL HTTP POST to the REAL, DB-backed network_add_node.php endpoint (Group A in the brain audit) — meaning if this file ever ran, it would insert fabricated garbage entities into the real entities table.
api/excavation_run.php calls api/excavate.php via a self-referential HTTP call (file_get_contents to localhost) rather than a direct function call — same fragile self-HTTP pattern as run_worker.php's shell_exec in the brain audit.
api/excavate.php is explicitly self-labeled in its own comment "SIMULATED MULTI-MODEL OUTPUT" — canned text per fake model (chatgpt/claude/gemini/perplexity), uses rand() for fake risk/confidence scores. Same "simulate N AI models with canned text" pattern already seen in the brain audit's model_router.php.
3. ExcavationCommand/ directory — unrelated orphaned dev-tool, shares the name only. Titled "LEGAiSEE GOD MODE" — a self-referential codebase file browser: system_index.php scans the app's OWN folders (modules/engine/kernel/api/pages/data) and caches the tree to system_index_cache.json; dashboard.php renders that as a browsable folder tree. Separately contains planner.php, a broken task-list stub that references an undefined $tasks variable (would fatal if ever POSTed to). Zero inbound references from anywhere else in the codebase — fully orphaned, reachable only by someone navigating directly to /ExcavationCommand/dashboard.php by URL. Has nothing to do with artifact excavation/pattern-mining — the name is coincidental.
lib/semantic_diff_engine.php — genuinely good, complete, orphaned. Strong RESTORE candidate.
Real, well-built DB-backed function: fetches two entities from the real page table via kernel_db()/PDO, computes an actual Jaccard-similarity text comparison (not fake), weighted importance scoring across 5 change types (title/meaning/tags/relationships/cluster), and generates a real formatted executive-summary text report. Required by 6 files in the fake flat-JSON universe already confirmed dead in legaisee-brain-micro-audit (compressor.php, event_emit.php, build_edges.php, compare_networks.php, mesh.php, create_network.php) — but none of them ever actually call semantic_diff() or any of its functions. Confirmed zero real callers anywhere in the codebase. Unlike most orphaned code found so far, this is real working logic that's just missing a live caller — a genuine candidate for hooking up to a real endpoint rather than deleting, once triage happens.
