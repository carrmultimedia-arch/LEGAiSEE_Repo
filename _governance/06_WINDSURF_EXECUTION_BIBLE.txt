# NON-NEGOTIABLE ARCHITECTURE RULES

## 1. NO STANDALONE PAGES

NEVER create:

* random php pages
* test pages
* temp dashboards
* utility pages
* debug pages

All features are modules:

```text id="s1rn1j"
modules/{name}_module.php
```

Registered in:

```text id="pjlwm1"
kernel/module_registry.php
```

Loaded through:

```text id="zjlwm2"
shell.php?module=name
```

NO EXCEPTIONS unless explicitly approved.

---

## 2. NO INLINE CSS

NEVER add:

```html id="hjlwm3"
<style>
```

NEVER embed CSS in:

* modules
* pages
* artifacts
* templates

ALL CSS goes into:

```text id="ujlwm4"
ui/global.css
```

Use module-prefixed class names only.

---

## 3. DO NOT MODIFY SHELL ARCHITECTURE

```text id="2jlwm5"
shell.php
```

is a router only.

Do NOT:

* inject app logic
* render multiple modules
* bypass module loading
* convert into SPA architecture
* add API logic

---

## 4. MODULES RETURN FRAGMENTS ONLY

Modules NEVER output:

* DOCTYPE
* html
* head
* body

Modules return:

* fragments
* strings
* ob_start()/ob_get_clean()

Pattern:

```php id="7jlwm6"
ob_start();
?>
<div class="module-wrap">
    ...
</div>
<?php
return ob_get_clean();
```

---

## 5. ALL AJAX USES api/

JSON endpoints MUST live in:

```text id="8jlwm7"
api/
```

NEVER return JSON through shell.php.

Pattern:

```text id="9jlwm8"
api/{name}_action.php
```

NEVER:

* raw mysqli

* global connection hacks

ALWAYS:

