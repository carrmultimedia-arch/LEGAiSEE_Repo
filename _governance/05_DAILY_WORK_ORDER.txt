OBJECTIVE

Two scoped upgrades to the Command Center:


PM Module — Project Creation
Add the ability to create and manage Projects as a parent container above Tasks. Currently pm_tasks (built in WO-002) has no project association — tasks are flat. This adds a pm_projects table, a project-creation UI in pm_module.php, and a project_id foreign key linking tasks to projects.
Ingest Linking — Multiple Sessions Per Task
Currently ingest linking assumes a 1:1 relationship between an ingest/session record and a task. This upgrade replaces that with a join structure so one task can accumulate multiple ingest sessions over time (e.g. a task that spans several excavation sessions), without losing the existing single-session records already in production.


Both upgrades follow architecture-locked rules: kernel_db() is the sole DB access pattern, shell.php is the sole routing entry point, ui/global.css is the sole permitted stylesheet, and all deliverables are complete replacement files — no patches, no snippets.

2.2 Database — Join Table

sqlCREATE TABLE task_sessions (
  link_id INT AUTO_INCREMENT PRIMARY KEY,
  task_id INT NOT NULL,
  session_id VARCHAR(64) NOT NULL,
  linked_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  notes TEXT,
  FOREIGN KEY (task_id) REFERENCES pm_tasks(task_id) ON DELETE CASCADE,
