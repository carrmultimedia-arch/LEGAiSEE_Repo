### 3B — Add case_id to review_flags

Check if column already exists:
```sql
SHOW COLUMNS FROM review_flags LIKE 'case_id';
```

If it returns nothing, run:
```sql
ALTER TABLE review_flags
ADD COLUMN case_id INT NULL DEFAULT NULL AFTER context,
ADD INDEX idx_review_flags_case_id (case_id);
```

This is required for report assembly to tie confirmed findings to specific
client cases. Nothing in the report pipeline works without this.

---

### 3C — Verify embeddings Table

```sql
SHOW TABLES LIKE 'embeddings';
```

If it doesn't exist, run:
```sql
CREATE TABLE embeddings (
    id INT AUTO_INCREMENT PRIMARY KEY,
    source_table VARCHAR(64) NOT NULL,
    source_id INT NOT NULL,
    context VARCHAR(32) NOT NULL DEFAULT 'legaisee',
    embedding_model VARCHAR(64) NOT NULL DEFAULT 'text-embedding-3-small',
    vector_data MEDIUMTEXT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_embeddings_source (source_table, source_id),
    INDEX idx_embeddings_context (context)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

Note: This table will remain empty until the embedding pipeline is built
in WO-002. Creating the schema now prevents migration blockers later.
